The Type Library

活字

22 families, 34 subsetted woff2 files, 6.9 MB, all SIL Open Font License and all bundled — built by tools/font-pipeline/build_fonts.py. Nothing depends on what happens to be installed on a player's machine, which the last pass learned the hard way.

The size trick: exactly one face carries full CJK coverage (Shippori Mincho, 2.8 MB, because a document must render whatever a GM types). Every other Japanese face is display-only and gets a subset of our own authored vocabulary instead — 83 KB instead of 2.8 MB. That is the difference between a 7 MB bundle and a 30 MB one.
