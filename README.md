# Blank Inheritance
### 空白相続 — Kuuhaku Souzoku

A Starfinder Second Edition campaign for six players and one GM. Each player runs two characters: a school-age kid (level 1) and a Frame — a multi-storey combat mech, fixed at level 12 and built as a full PC. The kids' lives outside the cockpit gate how much of the Frame's power they can actually use in a fight. Same emotional shape as Neon Genesis Evangelion, run through Starfinder's bounded-accuracy math.
