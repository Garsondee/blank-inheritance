# Abomination Vaults: the 2025–26 run

> **SOURCE MATERIAL — a separate, later run, not the founders' campaign.**
> This is a second Pathfinder 2e run of Paizo's *Abomination Vaults* with a different party, played on Foundry v14. It is
> **not** Blank Inheritance canon and has no known connection to the founders. It is kept because it was on the same
> server and "everything" was asked for. See `../README.md` for the rules.

*Extracted 2026-09-24 from `old server data/abomination-vaults/` (Foundry world title: "Abomination Vaults"). The chat
log runs from 19 November 2025 to 8 April 2026. The world was last played on 21 April 2026.*

---

This run follows the published adventure far more closely than *The Trouble with Mitflits* did. Almost everything in the
world is Paizo's own content (indexed by name in `published-content-index.md`). What's homebrew is the party and the
confidant notes the GM wrote onto each character's sheet.
