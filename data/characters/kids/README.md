# Kids

One JSON file per kid, conforming to [`../../schema/kid.schema.json`](../../schema/kid.schema.json). Filename should match the `id` field, kebab-case (e.g. `naomi-oduya.json`).

None of the six kids exist yet. Names, classes, backgrounds, and Anchors are collaborative creative decisions between the GM and players — not something to pre-generate to fill out the roster. See the design bible's [Naming Placeholders](../../../design/design-bible.md#naming-placeholders) section and the `frame-class-assignment` entry in [`../../campaign/open-questions.json`](../../campaign/open-questions.json) before filling these in.
