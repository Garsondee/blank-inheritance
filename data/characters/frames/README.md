# Frames

One JSON file per Frame, conforming to [`../../schema/frame.schema.json`](../../schema/frame.schema.json). Filename should match the `id` field, kebab-case. Each Frame's `pilotKidRef` should point at the matching file in `../kids/`.

None of the six Frames exist yet. Class, ability-band sorting, and reflavoring are collaborative creative decisions between the GM and players — not something to pre-generate to fill out the roster. See the design bible's [Characters](../../../design/design-bible.md#characters) and [Core Mechanic: Two Tracks](../../../design/design-bible.md#core-mechanic-two-tracks) sections, and the `frame-class-assignment` entry in [`../../campaign/open-questions.json`](../../campaign/open-questions.json), before filling these in.
